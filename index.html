Как установить

  1. Откройте эту страницу на телефоне Android и нажмите «Скачать Bloom».
  2. Когда файл скачается, нажмите «Открыть». Если телефон спросит, разрешите браузеру устанавливать приложения («Неизвестные приложения» → «Разрешить»).
  3. Если Google Play Защита предупредит о неизвестном разработчике, нажмите «Подробнее» → «Всё равно установить». Это тестовая версия, её ещё нет в Play Маркете.
  4. Откройте приложение Bloom Dev и выберите English или العربية.

Чтобы Bloom говорил

Настройки → Система → Языки → Синтез речи → Google → установите английский и арабский голос.

Что проверить

  • Сад, «Путь мышления» и новые задания: дорожка цифр, обводка пальцем, две корзины, тайный код, счёты, дороги букв.
  • Talk: составить фразу и послушать её.
  • Арабский интерфейс, звук и музыку (их можно выключить).
  • Удобно ли ребёнку, всё ли спокойно и понятно.

Напишите замечания тому, кто прислал вам эту ссылку: модель телефона, что делали и что заметили. Новые версии ставятся поверх по этой же ссылке, данные сохраняются. Приложение работает без интернета и ничего никуда не отправляет.

How to install

  1. Open this page on an Android phone and tap Download Bloom.
  2. When the file has downloaded, tap Open. If the phone asks, allow your browser to install apps (Install unknown apps → Allow).
  3. If Google Play Protect warns about an unknown developer, tap More details → Install anyway. This is a test version and is not on Google Play yet.
  4. Open Bloom Dev and choose English or العربية.

To hear Bloom speak

Settings → System → Languages → Text-to-speech → Google → install the English and Arabic voices.

What to try

  • The garden, the thinking path and the new tasks: number trail, finger tracing, two baskets, secret key, abacus, letter roads.
  • Talk: build a sentence and listen to it.
  • The Arabic layout, sound and music (both can be turned off).
  • Whether everything feels calm and clear for a child.
